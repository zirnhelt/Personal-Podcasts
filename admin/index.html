Connect to GitHub

This admin page has no server: it reads and writes config/profiles/*.json in the repository directly through the GitHub API, using a personal access token that stays in this browser.

  1. Open GitHub → Settings → Fine-grained personal access tokens.
  2. Restrict it to the one repository this page manages, and grant exactly two permissions: Contents: Read and write and Actions: Read and write. Set an expiry.
  3. Paste the token below. It is kept in this browser's localStorage only — use "Forget token" (top right) to remove it.
"Generate now" dispatches the Generate Podcasts workflow on GitHub Actions.
